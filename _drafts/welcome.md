This is a **sample draft**, ready to replace with your own words. It only appears when running the local preview with `--drafts`.

## A little room to write

Write a project update, document a fix, or share something you learned. Posts are ordinary Markdown files, so you can focus on the words.

- Give your post a title.
- Add a short excerpt for the blog listing.
- Write the rest here.

> Start small. A useful note is a good first post.

### Code belongs here, too

```yaml
sensor:
  - platform: uptime
    name: Uptime
```

You can add [links](https://github.com/inventor7777), images, lists, and code blocks.

To publish, move this file into `_posts` and name it `YYYY-MM-DD-your-post-title.md`. Remove this sample text before publishing.
